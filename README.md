# Grandpa's Life Story

《我的童年与成长经历——刘天财爸爸的人生回忆录》

以柔和的中国水彩漫画，珍藏刘天财爸爸从福建童年、九岁赴菲律宾、十五岁求学，到成家养家、摸索谋生及留给后代的人生回忆。

- 讲述：刘天财爸爸
- 访谈记录：刘永发、金线、金玉，在永发家与当时92岁的爸爸闲聊时共同记录
- 整理成文：刘永发（刘天财之子）
- 漫画：十页、四十格，保留八章正文、前言与完整后记
- 插画：使用内置 ImageGen 创作；人物与场景为依据文字的艺术化呈现

## 阅读与运行

公开阅读：<https://kengcc.github.io/Grandpas-Life-Story/>

推送到 `main` 分支后，GitHub Actions 会核对原文和插画，并自动将 `dist/` 发布到 GitHub Pages。

网站由 HTML、CSS 和 JavaScript 构成，无须安装依赖或编译。在本目录启动本地静态服务器：

```sh
python3 -m http.server 8000 --directory dist
```

然后在浏览器打开 <http://localhost:8000>。

电脑端提供四格同屏、独立的长文阅读区和同屏翻页栏；手机端纵向展开四格，翻页按钮位于第四格末尾，点击后直接进入下一页开头。也支持章节跳转、画面放大、键盘方向键和打印全书。

网站使用设备自带的中文字体，无需等待外部字体下载。无需账户、登录凭据或服务器端服务即可运行此仓库中的静态网站。

## 文件

| 文件或目录 | 内容 |
| --- | --- |
| `dist/index.html` | 网站页面 |
| `dist/style.css` | 水彩绘本版式、响应式阅读与打印样式 |
| `dist/app.js` | 翻页、放大、章节导航与打印功能 |
| `dist/story.js` | 完整原文、四十格旁白与当前插画路径 |
| `dist/assets/` | 水彩原画，包括第二、三页修订版 |
| `source-article.txt` | 整理换行后的原文 |
| `source-article.json` | 按前言、八章、后记组织的原文 |
| `manuscript-review.json` | 与更新稿的文字比对记录 |
| `art-direction.json` | 插画风格、绘图提示词与修订记录 |
| `check.cjs` | 原文完整性与插画文件检查 |

当前阅读使用原画生成的全分辨率 WebP 图片，第二、三页采用 `-v3` 修订原画。PNG 原稿保留在仓库中；具体阅读图片路径见 `dist/story.js`。

## 加载优化

漫画采用质量 86 的 WebP，保留 1536 × 1024 分辨率；首页封面单独缩至 960 像素宽。图片文件名带内容指纹，页面脚本和样式带内容版本号，便于浏览器缓存与更新。当前页和封面加载完成后，在浏览器空闲时预取下一页；开启节省流量或使用 2G 连接时不预取。

更新插画或网页代码后，安装 Node.js 与 [cwebp](https://developers.google.com/speed/webp/download)，运行以下命令重新生成阅读图片和资源版本：

```sh
node scripts/optimize-images.cjs
node check.cjs
```

## 核对原文

已安装 Node.js 时，在本目录运行：

```sh
node check.cjs
```

检查会验证四十格旁白的顺序与完整性，确保前言、正文及后记没有遗漏、改写或额外旁白，并核对所有当前插画文件。比对时仅忽略空白排版、装饰分隔线，以及“⼥／女”的字形差异。

原文与绘图提示词均保留在仓库中，便于家人继续校对和维护。
